基于FPGA的可配置多波形信号发生器

开发环境：Vivado 2022.2、MATLAB R2026b
硬件平台：AMD Artix-7 XC7A35T

功能说明：
全Verilog RTL手写实现，核心是带相位抖动优化的DDS波形发生器，支持正弦、方波、锯齿、三角四种标准波形。相位抖动用16位LFSR实现，作用在相位截断低4位，实测1MHz正弦波SFDR能从60dB左右提升到68dB以上，杂散抑制效果明显。
内置16阶可重构FIR滤波器，低通/带通/高通三种模式一键切换，系数用MATLAB设计、汉宁窗加窗、12位有符号量化，滤波效果稳定。输出通过12位并行DAC接外部示波器，数据端打了一拍寄存器消组合毛刺，时序更稳。
输出幅度256级可调，按键切换所有参数，带20ms硬件消抖，不会串键。
工程做了模块化拆分，VGA双域显示的代码也写完验证过，这次集中精力优化信号输出质量，硬件就只接了DAC，VGA代码保留着，后续要加显示直接例化就行。
整套工程跑完了综合、实现全流程，时序收敛，资源占用不高，下载比特流就能直接上板跑。配套的MATLAB脚本可以生成ROM系数、算滤波器参数、测SFDR指标，方便改参数复现。

上板操作说明：
- KEY0：循环切换波形类型
- KEY1：循环切换滤波模式
- KEY2：增大输出幅度
- KEY3：减小输出幅度

目录说明：
1_rtl：核心Verilog源码，含FFT IP配置文件
2_coe：波形ROM初始化系数文件
3_constraint：FPGA引脚约束与时序约束文件
4_sim：各模块单独仿真的testbench
5_matlab：波形生成、滤波器设计、SFDR计算辅助脚本
